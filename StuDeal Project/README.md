# StuDeal App

The Next.js application for StuDeal. The submission README is at [`../README.md`](../README.md). Implementation evidence is in [`docs/IMPLEMENTATION-STATUS.md`](docs/IMPLEMENTATION-STATUS.md).

```bash
pnpm install
pnpm dev
```

Local data mode is `fixture` by default in `.env.local`. The app is designed to run at `http://localhost:3000`.
