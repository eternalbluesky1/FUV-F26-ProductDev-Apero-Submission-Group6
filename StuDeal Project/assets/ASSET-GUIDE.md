# StuDeal UI and mascot assets

Prepared 13 November 2026 for the StuDeal assignment PRD. StuDeal is spelled with one d. Mon remains the mascot. Screen mockups are generated visual concepts for a browser-based responsive web app; they are not production captures or implementation code.

## What is included

- `brand-reference.png` - refreshed StuDeal wordmark, Vietnamese tagline and color reference.
- `screens/01` through `screens/11` - desktop-browser visual concepts for splash/loading, home, onboarding, swipe deck, discovery, saved-offer summary, Ask Mon, Pocket, offer detail, web states, and the design system. Each screenshot shows the web experience, not a native mobile application.
- `mascot/` - the six original Mon poses plus four extra transparent variants for deal discovery, checking conditions, welcoming and considering.
- `verified-offer-snapshot.csv` - official-source examples with conditions and the date checked.

## Offer and brand accuracy

The catalog snapshot was checked against official brand pages on 13 November 2026. These are not StuDeal partnerships or endorsements. The Vietnamese-market examples include Galaxy Cinema, CGV Cinemas Vietnam and Highlands Coffee; several benefits are age-based or general member offers rather than student-only discounts. Price-variable offers must show that caveat. Re-check every source and condition before an actual public release; no automatic freshness guarantee exists.

The image generator approximates wordmarks and brand marks in the screen concepts. Those graphics are not official brand artwork. Before external publication or implementation, replace them with approved brand assets or plain text labels; retain source links and the non-affiliation notice.

## Mascot and visual guidance

Preserve Mon's rounded grape-purple pouch body, yellow top drawstring/bow, expressive face, coin detail and friendly tone. New poses are supplementary; keep the source forms alongside them. Core colors: grape purple `#5B3DF5`, coin yellow `#FFD23F`, cheeky pink `#FF6FA8`, mint `#22C79A`.

Use transparent mascot PNGs as illustrations and semantic web components for the UI. Do not embed screen screenshots as live pages. Maintain keyboard focus, text labels, readable contrast, reduced-motion support and a responsive browser layout.
